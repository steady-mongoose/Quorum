# Quorum

A desk for constituent pressure. One office, one window, one sentence.

Quorum is a local coordination tool for calls, letters, and group messages aimed at a legislative choke point: a committee chair, a floor leader, a county board. It does not dial, spoof, or invent a crowd. Each person logs their own contact. Logs stay on the device.

Federal, state, and county desks are included. Group leads paste a channel-ready message into Signal, WhatsApp, or a text thread, and lock other groups onto the same desk with a captain brief.

## Run

```bash
npm install
npm run dev
```

Open the app at `http://localhost:8080`.

## What stays on the device

Campaigns, contact logs, the cell, and pledged groups are stored in the browser. There is no shared national counter.
